JAV Subtitles Tool

每行填写一个 Jellyfin 服务器内的媒体根目录。Docker 部署请填写容器内路径。详情页入口、分段搜索和指纹计划任务都使用这些路径；留空时暂停处理媒体。

迅雷展示全部候选；SubtitleCat 在搜索面板单独选择语言。字幕下载后可打开校准面板，对齐并保存。

自动校准的 LLM 设置

填写 Chat Completions 基础地址，可包含 /v1。音频在服务器本地识别，接口只接收少量台词和字幕候选。
顶层参数覆盖默认值，嵌套对象保持原样；推理和服务商扩展参数按所选模型的支持情况填写。model、messages、stream、n 由插件设置。输出上限为 4096 token；未填写推理参数时沿用服务商默认设置。
填写请求头名称与字符串值组成的 JSON 对象，例如 x-opencode-session 和 User-Agent。每次 LLM 请求都会携带这些请求头；Authorization、Content-Type、Content-Length、Host 由插件设置。
