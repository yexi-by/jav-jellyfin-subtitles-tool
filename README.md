# JAV Jellyfin Subtitles Tool

在 Jellyfin 详情页按 JAV 番号搜索迅雷和 SubtitleCat 字幕。每个视频版本和 CD1、CD2 等分段分别查询、选择和保存；字幕有固定时间差时，可在独立预览面板自动匹配或手动对齐，再保存校准。

适配 Jellyfin **10.11.11**。处理 Jellyfin 已入库、位于配置路径内的本地电影、剧集及其附属分段。搜索和校准入口在 Web 详情页；其他客户端可读取保存后的外挂字幕，具体字幕格式支持取决于客户端。

## 安装与设置

在 Jellyfin **控制台 → 插件 → 存储库** 添加：

```text
https://raw.githubusercontent.com/yexi-by/jav-jellyfin-subtitles-tool/main/manifest.json
```

安装 **JAV Subtitles Tool**，重启 Jellyfin 并重新加载网页。已有 Subtitles Tool 用户通过相同插件 GUID 升级。

在插件设置的“处理路径”中，每行填写一个媒体根目录。Docker 部署填写容器内路径，例如 `/media/JAV`。留空时暂停处理媒体；详情页入口、搜索、下载、校准及指纹任务使用同一范围。

账号需要 Jellyfin 的字幕管理权限。下载需要视频目录可写；校准还需要插件数据目录可写。服务器需要能够访问两个字幕来源。

自动校准支持 Linux x64、Windows x64。完整发行包包含 SenseVoiceSmall int8、sherpa-onnx 1.13.8 CPU 程序及 multilingual-e5-small int8 候选筛选模型，无需安装 Python 或 GPU 环境。FFmpeg／FFprobe 使用 Jellyfin 的配置，视频始终只读。

在插件设置填写 **API Base URL、API Key、模型名称**，使用 OpenAI 兼容的 Chat Completions 接口。例如 DeepSeek 的基础地址为 `https://api.deepseek.com`，模型 ID 为 `deepseek-flash`。自定义参数填写 JSON 对象，顶层覆盖默认值并保留嵌套内容，可配置服务商支持的推理参数及扩展字段；`model`、`messages`、`stream`、`n` 由插件设置。未指定推理参数时沿用服务商默认值。输出上限为 4096 token；未配置或调用失败时仍可手动校准。

## 搜索和下载

1. 在详情页点击 **JAV 字幕**，选择视频版本及需要处理的分段。
2. 面板根据文件名、所在目录和条目标题提取番号。可修改“番号与分段”搜索词；每段分别保存当前输入。
3. 搜索同时查询迅雷和 SubtitleCat，先返回的候选先显示。**搜索全部分段**会查询当前版本的每个分段。
4. 查看名称、来源、分段提示和格式后，手动选择下载。
5. 每段视频只保留一份外挂字幕，下载新的直接替换当前字幕。保存后 Jellyfin 刷新字幕信息，可以播放核对并校准。

### 来源规则

- **迅雷展示全部语言的候选**，不读取或推断语言，也不按语言筛选、分组或排序。
- **SubtitleCat 语言选择仅作用于 SubtitleCat**。默认查询已有简体、繁体中文，可选择其他语言或全部已有语言。只读取真实 Download 链接，不触发站点翻译。
- SubtitleCat 默认检索没有可用候选时，补查番号紧连、空格和省略前导零的写法；找到后停止补查。番号查询要求候选名称能确认相同番号，避免宽泛搜索混入其他影片。相同前缀、数字部分一致的番号按补零等价匹配，例如 `IKUNA-001` 与 `IKUNA-01`，仍需核对字幕版本。
- 已有有效 CID／GCID 时，迅雷追加文件查询；没有记录时，名称查询仍然立即进行。点击“按视频文件进一步搜索”才会读取当前文件并生成记录。
- 每个来源最多同时处理两个请求，成功响应缓存 15 分钟。关闭面板取消尚未完成的查询和计算。
- 番号检索排除明确属于其他番号的结果。来源未标清分段的候选提示“待确认”；源站按指纹返回的字幕也需要核对内容。

不同来源分别报告无结果、失败或部分成功。结果数量表示候选数量，不代表字幕质量、同步程度或整部影片已经配齐字幕。

### 分段和版本

分段关系以 Jellyfin 的附属分段信息为准。CD1、CD2 等文件各有自己的指纹、搜索结果、保存文件和校准记录。多清晰度版本及 `1080p-1/1080p-2` 等名称不会仅凭末尾数字被当成分段。

名称检索先使用分段搜索词，再用主番号补充召回。明确匹配其他已知分段的候选归入对应分段；字母或段号标记仍需核对实际切分位置。没有对应分段字幕时保持“未找到”或“待确认”，不自动拆分整片字幕，也不自动下载其他段的字幕。

### 文件命名

例如视频为 `ABC-123-cd2.mp4`，从迅雷下载后的字幕为 `ABC-123-cd2.xunlei.srt`；再下载 SubtitleCat 简体字幕时，当前字幕替换为 `ABC-123-cd2.subtitlecat.zh-Hans.srt`，前一份字幕及其校准记录移除。

支持下载和校准 SRT、ASS、SSA、VTT，保留文本、样式和原始编码。其他格式在结果中说明当前限制。不同来源、语言和格式都替换同一段视频的当前字幕，其他版本与分段独立保存。下载内容先校验，再替换；失败时保留当前字幕。

SRT 时间行中的全角冒号、简写箭头 `->` 和零宽字符会在保存时修正为标准时间格式；缺少序号的字幕时间块会补上序号，供 Jellyfin 识别。字幕正文、原有序号和编码保持；没有有效时间轴的下载内容会报告错误。

## 自动对齐与手动校准

适合“片头多了一段广告，后面始终相差相同秒数”的情况。

1. 在“已保存的字幕”旁点击 **校准**。
   桌面面板左侧显示视频和字幕时间轴，右侧显示校准操作。字幕列表内部滚动，当前对白、对齐、微调和保存按钮保持可见。
2. 点击 **自动对齐**，本地识别少量音频中的实际台词，筛选字幕候选，再由 LLM 确认具体字词与字幕条目的对应关系。多音轨视频可选择预览及分析使用的音轨。分析期间可以取消；关闭面板后任务继续，重新打开可查看结果。
3. 找到时间差一致的具体对应后，“本次调整”显示建议偏移，并展示实际台词与对应字幕。可切换核对的对白，点击 **预览对应对白**检查，再继续微调并 **保存校准**。找不到明确对应时不填入结果，可将播放位置移到清楚的对白附近，点击 **从当前播放位置之后匹配**重试。对白稀疏时，普通分析可能需要这种位置提示。

手动操作保持原有步骤：

1. 选择一句容易辨认的字幕，将视频暂停在实际说出这句话的开始处。
2. 点击 **对齐到这里**，插件计算整份字幕需要移动的时间。
3. 用“提前 0.5 秒”“延后 0.5 秒”微调，或输入秒数；正数延后、负数提前。
4. 播放核对，再检查后面一处对白，点击 **保存校准**。

自动分析只读取视频和当前字幕，保存前不会改写字幕。下载其他字幕、外部替换字幕或视频发生变化后，旧建议失效，需要重新分析。对已保存校准的字幕再次分析，建议表示相对于当前文件的剩余时间差。

自动校准按“视频中实际台词的开始时间 − 当前字幕条目的开始时间”计算固定偏移。至少两句互不重叠的具体对白支持一致的偏移（差不超过 0.75 秒）后，取中位数作为建议；可以来自同一段对话或不同位置。同一句台词、重叠字幕不能重复充当核对点。首条字幕不预设为锚点；画面标题、字幕组宣传、无对应台词的说明，以及非语言人声不参与匹配。只对应合并字幕中间的子句、无法确定条内起点时，另选锚点。上述字幕仍保留，随整份字幕的偏移一起移动。字幕来源和视频版本无需先经过认证，实际能否对应由台词核对决定。

普通分析在约 5%、50%、80%、20% 位置及附近有限搜索，每段最多 30 秒，最多八段、总计 4 分钟音频；找到具体对应后，优先读取附近另一段对白核对，并根据已有时间差缩小字幕候选范围。从当前播放位置重试时，先读取附近，再向后有限搜索。找到两处时间差一致的明确对应后结束。初次自动候选限定在当前时点前后 15 分钟，避免远处相似场景导致巨大的错误偏移；超出范围可手动校准。VAD 只切分音频、跳过静音；本地向量分数只筛选候选，均不作为对应成功的证据。

音频在本地处理，LLM 只接收少量识别字词、字幕候选和附近上下文。每段最多 3 次请求，每次任务最多 24 次，包含起点复核及最多一次网络重试，每次超时 60 秒，业务文本上限 12,000 字符。默认 temperature 为 0，自定义参数可覆盖。服务器同时运行一个任务，CPU 模型最多使用 2 个线程，整个任务最长 5 分钟。任务仅保存在内存中，临时音频在结束或取消后清理；固定 CPU 资源提取到 Jellyfin 缓存后复用。

程序逐项校验 LLM 的 JSON 格式、语句与字幕 ID、原文引用及字幕起始位置。台词起点通过对应开头原文在带时间戳的字词中唯一定位，避免识别语句包含前一句问话时从错误位置起算。输出错误时，将具体错误和修正要求作为下一条消息反馈，在请求额度内重试；有歧义的起点单独复核，明确对应与另一句独立台词交叉核对。合法的“不匹配”结果进入下一处有限取样，不强迫模型选择字幕。候选对应不足、时间差明显冲突或额度用完时返回“不确定”，状态区说明原因，保留手动校准入口。

保存直接调整当前外挂字幕，不保留下载原稿或恢复副本。“本次调整”表示相对于当前文件的移动量，例如先延后 30 秒，再延后 2 秒，累计延后 32 秒。保存后输入归零，并显示新的时间轴。提前到 0 秒之前的条目会裁去；没有原稿时，裁去的条目无法恢复。插件数据目录 `jav-subtitles-tool/calibration` 只保存绑定视频和字幕的当前校验记录。

记录绑定具体视频文件及字幕；视频或字幕被外部替换时，需要确认以当前文件重新开始。保存后请重新加载字幕，并把播放器原有的临时偏移归零。所有读取这份字幕的用户共享校准结果。

本版处理整份字幕的固定偏移。中途插入广告、删减片段或播放速度不同，需要分段或比例校正，不属于当前校准功能。带分片时间映射的 VTT 暂不支持处理。

## 空闲时生成视频指纹

在 **控制台 → 计划任务 → JAV Subtitles Tool → 生成 CID、GCID 记录** 设置触发时间，或手动运行。新安装的初始触发器为空；从旧版升级会保留已有触发时间。

任务覆盖配置路径内的媒体版本及其附属分段，复用有效记录。Jellyfin 有正在播放的会话时等待，暂停播放后继续；手动计算优先。停止任务后，已完成记录保留，未完成文件下次重新计算。

失效媒体路径和范围外条目跳过并汇总；记录损坏、读取或写入失败会记录原因。损坏记录保持原样，修复后可重试。

记录文件与视频同目录，文件名保留视频扩展名：

```text
ABC-123-cd2.mp4
ABC-123-cd2.mp4.cidgcid
```

记录为 UTF-8、无 BOM、以换行结束的两行文本：

```text
CID=E3908EE98B37C56925CB036554850D360AE2510D
GCID=DB1F8AB96B65E05022A6211DA4226D52F8E54B16
```

上述数值为测试向量。在外部替换同名视频后，应删除其旧记录，再重新生成。指纹计算只读访问视频。

## 开发和发布

工具版本由仓库固定：.NET 9 SDK、Node 24、pnpm 12。

```powershell
cd webui
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
cd ..
pwsh -File scripts/fetch-speech.ps1
dotnet test Jellyfin.SubtitlesTool.sln
pwsh -File scripts/package.ps1
```

前端构建在后端构建之前执行；页面脚本和按需加载的校准模块嵌入插件 DLL。资源脚本下载并校验固定来源的原生程序、模型和 tokenizer，打包时也会核验。安装包包含主程序集、托管依赖、`speech-assets.zip`、依赖说明和许可文件；资源清单嵌入程序集，使用时逐文件核对大小及 SHA256 并提取到缓存。原生 DLL 保存在资源包和缓存中，避免服务器将它们当作插件扫描。

推送与项目版本一致的标签，例如 `v0.5.0.0`，GitHub Actions 会检查、打包、发布 Release 并更新插件清单。内部程序集名称、插件 GUID 和计划任务类型保持稳定，用于连续升级。Web 集成只修改入口响应，不修改磁盘上的 Jellyfin Web 文件。
